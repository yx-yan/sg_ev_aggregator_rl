# 窗口 B 再交付：服务价值表（情景研究，2026-11-11）

**情景研究**：调频激活曲线、削峰单价、新加坡是否允许 EV 聚合负荷提供调频，都是假设或待确认。所有数值都是完全预知 LP 的上限。

## 一句话结论

在公共桩上，调频容量是最值得做的服务：在智能充电的基础上，它每端口每天多带来约 S$0.21（普通周）到 S$0.30（尖峰周）。V2G 单独做套利几乎不值钱，普通周每端口每天只多 S$0.02。V2G 的价值主要体现在给调频提供对称余量（普通周 +S$0.14，尖峰周 +S$0.42）。建议保底版本做"智能充电 + 调频"，V2G 作为扩展情景，削峰的价值完全取决于假设的单价。

## 关键结果

设置：100 个公共端口，7 天一个 episode，用训练期和验证期全部 65 个完整周（周一到周日）。按窗口 C 的标签，其中 58 周普通、7 周尖峰；按价格水平分是 52 周普通、13 周高价。50% 的 AC session 可以 V2G。每端口每天约 1.35 个 session。表：`tables/services_base_*.csv`、`services_sensitivity.csv`、`services_check.json`；图：`figures/services_saving_sources.png`。

### 1. 各情景每端口每天成本（S$，全部 65 周平均）

所有情景都按同一个削峰电价（15:30–17:30 净用电 0.10 S$/kWh）结算，所以相邻情景之差就是该服务的价值。

| --- | --- | --- | --- | --- | --- | --- |
| S1 不控制 | 3.825 | 0 | 0 | 0.324 | 4.149 | — |
| S2 智能充电 | 3.481 | 0 | 0 | 0.322 | 3.803 | 0.346 |
| S3 + V2G | 3.415 | 0.021 | 0 | 0.322 | 3.758 | 0.391 |
| S4a 智能充电 + 调频（无 V2G） | 3.550 | 0 | 0.297 | 0.331 | 3.584 | 0.565 |

S4 折合每端口每年约 S$267（普通周 S$219，尖峰周 S$666）。

### 2. 普通周和尖峰周（每端口每天的增量，S$）

| 增量 | 普通周（58） | 尖峰周（7） |
| --- | --- | --- |
| 智能充电（S2 − S1） | 0.255 | 1.101 |
| V2G 套利（S3 − S2） | 0.018 | 0.268 |
| 调频，无 V2G（S4a − S2） | 0.209 | 0.303 |

按价格水平分：高价周（13 周）S4 比 S1 省 1.11，普通周（52 周）省 0.64。

### 3. 敏感性（S5 全部服务比 S1 省多少，每端口每天，21 周子集）

基准为 1.055（子集包含全部 7 个尖峰周，所以高于全年平均）。

| 参数 | 取值 → 节省 |
| --- | --- |
| V2G 比例 | 0 → 0.83；0.25 → 0.94；0.5（基准）→ 1.06；1.0 → 1.29 |
| 削峰单价（S$/kWh） | 0.05 → 1.02；0.10 → 1.06；0.20 → 1.16；0.50 → 1.49 |
| 电池损耗（S$/kWh） | 0 → 1.08；0.03 → 1.07；0.06 → 1.06；0.10 → 1.05；0.15 → 1.04 |
| 放电效率 | 0.88 → 1.05；0.92 → 1.06；0.95 → 1.06 |
| 到达 SoC | 低 → 1.04；中 → 1.06；高 → 1.00 |
| 调频电量余量比例 | 0 → 1.06；0.25 → 1.05 |

- **V2G 比例和削峰单价**影响最大，电池损耗、效率、到达 SoC 的影响都不大。
- 到达 SoC 影响小，是因为公共桩上大部分灵活性来自 AC 长停留，而这部分车无论 SoC 高低都有余量。只看智能充电（S2），到达 SoC 低和高的差别更明显：0.55 对 0.45。

### 4. 回答计划里的三个问题

- **V2G 在普通周和高价周分别值多少**：只做套利时，普通周 S$0.02、尖峰周 S$0.27（每端口每天）。和调频一起做时，普通周 S$0.14、尖峰周 S$0.42。
- **哪项服务放进保底版本**：调频容量（无 V2G 时也有 S$0.21–0.30）。V2G 套利单独做不值得，建议只作为"V2G + 调频"的扩展情景。削峰的价值完全由假设的单价决定，可以作为一个简单的电价项保留，不需要单独开发。
- **成本主要来自哪里**：电费占绝大部分（每端口每天 S$3.4–3.8）。服务收入是第二位（调频 S$0.30–0.41）。电池损耗很小（≤ S$0.03），因为 V2G 放电量本身很少。

### 5. 检查项

- 没有出现同时充放电（所有周、所有情景都是 0 步），所以不需要二进制变量。
- 最慢的 LP 求解只用 0.19 s。
- 规模提醒：100 个端口平均只能提供约 0.09 MW 的调频容量。如果市场有最小投标规模（待确认），可能需要 1,000 个以上的端口才能参与。

## 用了哪些假设

| 项 | 值 | 依据 |
| --- | --- | --- |
| 调频收入 | 只按 `regulation_price` 计容量收入，不计激活电量的成本和未达标罚款 | 假设；没有公开的 AGC 信号 |
| 调频激活 | 每个时段内电量中性，另按 0.1 的比例给电池留余量 | 假设，敏感性 0–0.25 |
| 调频资格 | 假设 EV 聚合负荷可以参与，没有最小规模限制 | **待确认**（新加坡市场规则） |
| 削峰窗口 | 训练期毛需求平均曲线最高的 4 个半小时：15:30–17:30 | 数据 |
| 削峰单价 | 0.10 S$/kWh（净用电），所有情景都按它结算 | 假设，敏感性 0.05–0.50 |
| V2G | 只有 AC session 可以，比例 50%，放电功率 = 充电功率 | 假设；新加坡没有商用 V2G |
| 放电效率、电池损耗 | 0.92、0.06 S$/kWh（按电池放出的电量计） | 假设，和窗口 C 一致 |
| SoC 下限 / 上限 | 0.2 / 0.95（到达或目标超出时放宽到该值） | 假设 |
| 到达 SoC | 中档（AC 0.2–0.7、DC 0.1–0.5），低档和高档做敏感性 | 假设，见 `2026-11-11_env_lp.md` |

## 没完成什么

- 只有 LP 上限。V2G 和调频还没有接进环境，规则基准和 RL 还不能做这些服务，所以也还没有 V2G/调频的 LP 回放检验。
- 需求响应（DR）没做。
- 1,000 端口的服务价值表没跑；只在只充电时检查过 1,000 端口的求解速度。
- 调频资格和最小规模还没核实。
